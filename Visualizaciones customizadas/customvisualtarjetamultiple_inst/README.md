# Power BI Custom Visual: Tarjeta Multiple

Este proyecto contiene un visual personalizado para Power BI, con soporte para formato avanzado, overrides por métrica, y opciones de presentación.

## Estructura
- src/: Código fuente TypeScript
- style/: Estilos LESS
- assets/: Recursos
- pbiviz.json: Configuración del visual

## Uso
- Compilar: `pbiviz package`
- Instalar dependencias: `npm install`

## Versionado
- El proyecto está preparado para Git y GitHub.
- Puedes hacer rollback fácilmente usando commits.
